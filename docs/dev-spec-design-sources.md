# Dev-spec design sources

Reviewed 2026-10-19 using primary sources. Scripts are original; upstream ideas were adapted rather than copying instruction packs wholesale.

| Source                                                                                                                                                                                                | Adopted                                                                                                                     | Deliberately omitted                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |

Spec Kit places data-model/contracts in planning output. Here logical concepts and external behavior live in dev-spec; storage/runtime architecture remains in dev-plan. Threadnote native recall, citations, typed relations, immutable input pins, transactional persistence and coordinated retirement provide the shared memory workflow.
