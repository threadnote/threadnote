# Implementation practice

Begin from the current plan, source graph, repository guidance, and exact acceptance. Read the current phase plus necessary dependencies, not every linked document. Refresh the graph before unfamiliar source discovery; use exact-path reads for known relationships.

Implement a small working slice. Preserve assertions and prior accepted behavior. Run focused checks during changes, then every required phase check on the actual final tree. Keep source edits separate from generated state and never claim unrun verification.

Use the least costly approach that can meet the evidence and quality bar. Escalate only when the task exposes real uncertainty. Keep context, prompts, and progress updates bounded; report substantive blockers, not routine narration.
