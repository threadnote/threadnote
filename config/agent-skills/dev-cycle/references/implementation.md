# Implementation practice

Begin from the current plan, source graph, repository guidance, and exact acceptance. Read the current phase plus necessary dependencies, not every linked document. Refresh the graph before unfamiliar source discovery; use exact-path reads for known relationships.

Before assigning source work, read [delegation](delegation.md) and prepare the bounded implementation packet described there. Keep the orchestrator on coordination, integration, validation, and evidence; implementation remains with a background worker.

Implement a small working slice. Preserve assertions and prior accepted behavior. Run focused checks during changes, then every required phase check on the actual final tree. Keep source edits separate from generated state and never claim unrun verification.

Workers implement against the supplied scope and acceptance, then return a concise result with changed-artifact links and checks. Preserve the quiet-worker requirement in their prompts, including for descendants. The orchestrator integrates and checks the actual final tree; it does not fill implementation gaps itself.
