# Learning records

Capture reusable learning only when implementation produced a verified lesson that will help future work. Separate observed result from speculation; cite the relevant code or test evidence and include the condition where the lesson applies.

Keep feature-specific rationale in the feature’s durable knowledge. Do not silently promote policy or general guidance; use its separate approval path. Read back any saved learning and retain its native receipt. Avoid recording secrets, customer data, or raw production logs.
